ERPA: what it means and how to use it

ERPA = Expected Runs Prevented Above the pitcher’s usual supported pitch mix. This is this project’s definition, not an official MLB statistic. Its unit is runs per next pitch.

Run expectancy describes future scoring opportunity. A pitch can change it without ending the at-bat: a strike, a ball, a walk and a home run have different costs, which depend on the count, runners and outs. Expected run value (ERV) averages those possible costs using the model’s probabilities.

ERV(pitch) = Σ predicted outcome probability × estimated batting run impact Reference ERV = Σ this pitcher’s usual supported pitch frequency × ERV(pitch) ERPA(pitch) = Reference ERV − ERV(pitch)

Lower batting ERV is better; higher ERPA is better. Positive ERPA says the candidate is better than the reference. Negative says worse. A pitch may still allow positive batting run value and have positive ERPA if the reference is even less favorable. With only one supported candidate, ERPA is zero because that pitch is its own reference.

The baseline is this pitcher’s observed 2026 mix against this batting side at this count, normalized over supported options. It is held fixed across previous-pitch histories. The average-history view weights reachable histories by this pitcher’s observed usage; the exact-history view conditions on the selected previous pitch and result.

Illustrative example: fastball ERV −0.010, slider ERV +0.020, usual mix 60%/40%. Reference ERV is +0.002. Fastball ERPA is +0.012 runs/pitch, or +1.20 runs per 100 equivalent decisions. That is not 1.20 runs saved by one pitch, nor a projection for a 100-pitch game.

The reference’s average ERPA is zero by construction. A positive best pitch alone does not validate the model. The direct runner-up gap helps distinguish a preference from a near tie; “close” here means a gap below 0.001 runs/pitch, a display heuristic rather than a confidence interval.

ERPA is not ERA, actual runs saved, or win probability. It is not directly comparable between pitchers because each has a different baseline. The objective minimizes expected run change; it does not optimize protecting a one-run lead, walk-off risk, bullpen deployment, health, fatigue or pitcher availability.

Probabilities come from a shared model with separate pitcher profiles and supported repertoires. Current-pitch measurements and current-date outcome summaries are excluded from pre-pitch inputs. Run impacts use recorded Statcast delta_run_exp, pooled by count/base/out/outcome with smoothing strength 20. These are acquired-cohort estimates, not a newly measured full-league run-expectancy matrix.

Pitch choices and execution are observational. Location intent, catcher calls and selection effects remain uncontrolled; forecasts for an unthrown pitch are not proven causal benefits. Use the support warnings and recompute after the result of each pitch. A fixed sequence cannot account for every branch.
